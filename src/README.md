# Paradise Nursery - E-Plant Shopping Application

Paradise Nursery is a React-based web application designed for plant enthusiasts to explore, select, and manage their favorite indoor and air-purifying plants. Built with React and Redux Toolkit, the application offers an intuitive user interface, dynamic cart management, and seamless state tracking.

---

## 🌿 Features

- **Landing Page:** Interactive homepage featuring company details and a quick "Get Started" call-to-action button.
- **Product Catalog:** Itemized listing of plants categorized by types (e.g., Air Purifying Plants) with descriptions, pricing, and visual representations.
- **Shopping Cart Management:** Powered by Redux Toolkit for centralized state management:
  - Add items to cart dynamically.
  - Increase or decrease item quantities directly within the cart.
  - Remove items from the cart.
  - Real-time calculation of total quantity and cost.
- **Responsive Layout:** Modern, user-friendly CSS styling across device viewports.
